# M0 closeout and M1 TXT reading

Status: in-progress

## Outcome

Keep the 手不释卷 reader shell while completing the remaining M0 storage, reader, and macOS evidence work, then deliver the first M1 TXT capabilities: encoding detection and switching, conservative table of contents, bookmarks, and cancellable literal search. The release boundary remains defined by [the product requirements](../product/requirements.md) and [the roadmap](roadmap.md).

## Scope

Included work covers Rust TXT decoding and storage migration, staged re-decode publication and recovery, generated IPC contracts, application-owned decode and search cancellation, reader integration, TOC/bookmark/search panels, PageFlip cleanup, and native test isolation. The work preserves LF-normalized UTF-16 locators, Book and BookAsset identity, the existing visual shell, and explicit error states. EPUB, Legado sources, RSS, WebDAV, AIGC, full shelf management, and Android/Windows acceptance remain excluded.

## Interfaces

Rust models remain the sole IPC source and generate `src/types/generated.ts`. Library commands own TXT import, source re-association, and re-decode tasks; reader commands own content windows, TOC, bookmarks, and search. Re-decode retains raw source bytes, stages normalized UTF-8 and sparse indexes outside the database mutex, and publishes through `txt_decode_journal`. Search requests carry an optional operation identifier so the reader can cancel stale scans. Schema version 5 adds decode recovery state; version 6 adds persistent shelf groups and memberships. Both preserve existing Book and BookAsset IDs.

## Acceptance criteria

- UTF-8, BOM, GB18030/GBK, and UTF-16 TXT inputs decode to normalized LF text; manual selection persists and failed/cancelled re-decodes keep the prior version.
- UTF-16 locator windows, TOC entries, bookmarks, and search matches remain valid around emoji and window boundaries; stale search work cannot update a newer query.
- Repeated normalized imports do not replace an existing book's raw source or selected encoding; interrupted publication recovers on the next open.
- M0 native core, restart, failure, instant, animated, and crash-recovery flows remain deterministic; system-picker and native window close/quit evidence stay explicitly tracked until recorded.

## Review repairs

The current restored UI is the accepted visual baseline. This review preserves its hierarchy, colors, fonts, cards, group strip, and navigation. Deferred discovery and RSS controls are disabled, with sample identities, fabricated statistics, and external sample covers removed from production. Header/sidebar/dock material changes only the agreed background alpha values. Native presentation tests capture the same desktop and phone scenes before and after this repair.

Shelf group reads and mutations share an ordered queue; chapter requests update independently and reject stale results. Empty group snapshots remain empty, and invalid selections return to All. Failed chapter reads retain same-version information and expose a retry without hiding books. Local grouping uses the existing generated Rust API and schema 6; this repair adds no further IPC or migration.

Storage now rejects stale decode snapshots before publication, including encoding-only changes. Repeat imports prioritize retained source identity and rebuild missing assets using the selected encoding outside the database lock. Recovery protects committed source paths, while source repair publishes to operation-owned paths so rollback can remove only uncommitted files. Regression cases include legacy journals whose raw staging file was already removed. A failed locator/progress seek no longer enables saving over a stale saved position. Reader tool errors appear in their owning dialog, and decoding refreshes bookmark and directory state.

## Verification

`pnpm check` passed with 65 frontend tests, 37 Rust tests, generated-type consistency, documentation/boundary checks, Rust formatting/Clippy, and the frontend build. `pnpm tauri build --debug --no-bundle` passed as an ordinary macOS build. `pnpm test:native` passed: core 4, failures 5, restart 1, instant interaction 4, animated interaction 4, presentation 2, TXT tools 4, and crash recovery 1. The intentional crash phase was accepted only after its fault marker and process exit were verified.

Native presentation captured the restored baseline and repaired pages at 1100 x 820 and 390 x 780. Direct inspection and recorded geometry confirm unchanged shelf, reader, and settings layout/typography; discovery and RSS retain their regions with unavailable content. Removing sample lists eliminates overflow in those pages, so their former scrollbar gutter disappears. Additional native cases verify group editing/membership after reload, deletion of all groups without fabricated fallback, and scrolling behind light/dark/OLED glass. Screenshots and geometry remain in ignored `.native-artifacts/` directories.

System-picker selection/cancellation, native window close/quit, and source re-association evidence remain unverified; the suite's fixture import is not picker acceptance. The frontend build still reports a non-failing large-chunk warning.

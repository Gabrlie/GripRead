# M0 logic foundation

Status: in-progress

## Outcome

Deliver the M0 logic foundation that allows a later interface to import a UTF-8 TXT book, read bounded content windows, paginate from stable text positions, save progress, and restore it after restart. Behavior is owned by the [library](../subsystems/library.md) and [reader](../subsystems/reader.md) specifications.

## Scope

Implement the Tauri 2 application host, Rust local storage and file services, typed IPC bindings, TXT normalization and position services, and a framework-independent reading controller. Include a minimal smoke host for real macOS IPC verification. Keep full product screens, EPUB, source rules, RSS, WebDAV, AI/vector features, Android validation, and Windows validation out of this task.

## Interfaces

Rust is the source of truth for serializable IPC types. The frontend consumes generated TypeScript bindings through service wrappers. `Book` and `BookAsset` remain separate; TXT is represented as one resource. `ReaderLocator` uses normalized LF text and UTF-16 code-unit offsets that cannot split a surrogate pair. Import operations expose observable progress, cancellation, terminal errors, and commit only after staged data is complete.

## Acceptance criteria

- Import, read, save, close, and reopen a TXT through real macOS Tauri IPC and recover the same passage.
- Reimporting identical bytes reuses the asset/book identity; failed or cancelled imports leave no readable partial record.
- Large text, CRLF/CR input, Chinese text, and emoji remain contiguous across content-window boundaries.
- Reflowing after a viewport or typography change resumes from the locator; stale session results cannot overwrite a newer session.
- Missing assets and content-version changes return explicit recoverable states.

## Verification

Run the repository documentation checks, generated-binding freshness check, strict TypeScript checks, frontend build, Rust format/check/test, focused unit tests, and the macOS native smoke suite. Record each command, environment, result, and any unavailable target in the handoff section before marking the task completed.

On macOS arm64, `CI=true pnpm check`, `CI=true pnpm tauri build --debug`, `CI=true pnpm tauri dev` startup, and `CI=true pnpm test:native` were verified; the development host selects the `gripread` binary explicitly. WebdriverIO embedded tests are not included in this handoff because the test-only Tauri WebDriver plugin and runner still need to be added. Product pages, WebDAV, Legado compatibility, EPUB, Android, Windows, and AIGC remain outside this task.

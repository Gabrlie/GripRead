# GripRead：轻量、多端互通的小说与 RSS 阅读器

## 1. 产品定位与首版边界

核心体验是：**打开就接着读，换设备仍在同一段。**

首版覆盖 Android、Windows、macOS，以本地数据为基础，无需账号或 WebDAV 即可使用。配置 WebDAV 后，增加书架与进度同步、云端文件浏览和备份恢复。

包含三类阅读入口：

- **本地小说**：TXT、无 DRM 的流式 EPUB，支持目录、书签、搜索和离线阅读。
- **网络小说**：导入阅读书源，支持搜索、加入书架、更新检查、换源和章节缓存；首版兼容常用文本规则及有限 JS 能力。
- **独立 RSS 阅读器**：RSS/Atom 链接、OPML 导入导出、分组、未读、收藏和文章阅读。

RSS 独立于小说书源管理。阅读的 `rssSource` 网页规则、漫画、听书及 iOS/Linux 适配放入后续版本。

## 2. 页面结构与阅读体验

采用“安静的纸感”：暖白背景 `#F7F4ED`、墨色正文 `#292D29`、低饱和绿色 `#58705C`，提供对应深色主题。界面使用系统无衬线字体，正文支持宋体风格和用户导入字体；通过留白、细分隔线建立层次。

手机底部保留 **书架、找书、RSS、设置** 四个入口；桌面使用同名侧栏。进入小说正文后隐藏主导航。

| 页面 | 手机布局与交互 | 桌面布局与交互 |
|---|---|---|
| 书架 | 顶部“继续阅读”，下方封面网格或列表；长按管理 | 最近阅读置顶，支持网格、列表、多选和文件拖入 |
| 找书 | 搜索框、书源分组、逐步返回搜索结果 | 搜索结果与书籍详情并排，支持快速加书和换源 |
| RSS | 分组与文章列表逐级进入，正文上下滚动 | 订阅列表、文章列表、正文三栏，可收起侧栏 |
| 设置 | 阅读、书源、同步与备份、存储分组展示 | 左侧分类、右侧设置，结构与手机一致 |

**书架与云端书库**

书架默认展示最近阅读，并提供分组、在读、未读、已读筛选。书籍显示更新数量、阅读进度和本机可用状态。

启用 WebDAV 后，书架增加“云端书库”页签，直接浏览指定文件夹中的 TXT/EPUB。下载并加入书架后即可阅读；本地书籍菜单提供“上传到云端书库”。仅同步了书架记录、当前设备缺少文件时，明确提供“从云端下载”或“关联本地文件”。

**小说阅读页**

- 默认分页，提供仿真、平移、无动画三种翻页效果，也可切换滚动。手机默认单页，桌面默认居中单页，可开启双页。
- 点击正文中部呼出工具栏；底部首层仅保留目录、进度、外观、书签，换源和下载放在更多菜单。
- 默认正文字号 20px、行距 1.8；手机左右留白 24px，桌面单页正文宽度限制在约 720px。
- 支持滑动翻页、点击左右区域翻页，以及桌面方向键和空格键。选择文字时暂停翻页手势。
- 改字号、切换横竖屏、单双页或设备后，按正文位置重新分页；不使用页码作为同步依据。

**RSS 阅读页**

RSS 保持连续滚动，展示标题、来源、发布时间、正文和原文入口。默认显示订阅提供的内容；摘要型文章可按需提取全文，失败时仍可阅读摘要并打开原文。订阅配置、已读和收藏状态可以同步，文章与图片缓存留在各设备。

空状态直接给出“导入书籍”“添加书源”“添加 RSS”等入口，不要求先配置云服务。

## 3. WebDAV 与同步设计

三种能力分别设置，避免混淆：

| 能力 | 保存内容 | 触发方式 |
|---|---|---|
| 自动同步 | 书架、分组、进度、书签、书源、RSS 订阅及阅读状态、通用偏好 | 启用后自动运行 |
| 云端书库 | 用户主动上传的 TXT/EPUB | 手动上传、按需下载 |
| 备份恢复 | 带版本的数据与配置快照 | 手动备份；有变更时每日自动备份 |

默认目录采用 `/GripRead/Books`、`/GripRead/Sync/v1`、`/GripRead/Backups`，允许指定已有书库文件夹。小说正文缓存、RSS 内容缓存不进入同步和备份；WebDAV 凭据、书源登录态和本机路径也不上传。字号、字体文件、窗口尺寸按设备保存。

**同步行为**

- 操作先写本地 SQLite，再进入持久化同步队列；同步故障不影响本地阅读。
- 阅读进度变化后合并上传：默认延迟 3 秒，连续阅读最多间隔 10 秒上传一次。切后台、退出阅读时尽力提交，未完成任务下次恢复。
- 启动、切回前台、打开书籍时立即检查云端；阅读期间每 15 秒检查当前书籍。设置中提供手动同步。
- 首屏先显示本地内容。阅读开始后发现新的远端进度，只提示“另一台设备读到了……”，由用户决定是否跳转。
- 正常状态仅显示小型同步图标和最近成功时间；离线、认证失败、冲突时提供具体操作入口。

WebDAV 使用文件读写与条件请求实现同步；快速续读通过上述触发机制完成，不依赖服务端推送。[WebDAV 标准](https://www.rfc-editor.org/rfc/rfc4918.html)

**冲突与恢复**

每台设备独立写入状态文件，进度单独保存，记录实体版本和删除标记。根据版本关系合并顺序更新；并发修改同一字段时保留双方值。

两台设备离线阅读造成分叉时，展示设备、章节和文字片段供选择，不按最大阅读百分比或设备时间直接覆盖。书架移除操作同步到其他设备，但不会删除云端原书文件；清除缓存只影响本机。

自动备份默认保留最近 7 份，手动备份单独保留。恢复前展示内容摘要并创建本地恢复点，恢复结果作为新变更进入同步。

## 4. 技术架构与接口

采用 **Tauri 2 + React + TypeScript + Vite + Tailwind CSS + shadcn/ui**。Tauri 负责三端容器及原生能力，前端负责页面、排版和交互；Rust 负责数据库、文件、网络、解析和同步。[Tauri 官方介绍](https://v2.tauri.app/start/)

shadcn/ui 用于导航、表单、弹层和设置。手机操作面板使用 Drawer，桌面使用 Dialog 或侧面板，正文区域独立实现。[响应式 Drawer 文档](https://ui.shadcn.com/docs/components/radix/drawer)

逻辑上分为四个模块：

- **阅读核心**：将 TXT、EPUB 和网络章节转换为统一章节文档，负责内容定位、分页和书签；仿真动画使用封装后的 StPageFlip，仅接收已分页内容。[StPageFlip 官方项目](https://github.com/Nodlik/StPageFlip)
- **书源引擎**：在 Rust 工作线程运行 QuickJS-NG，通过 rquickjs 提供有限宿主桥；保留常用脚本中同步 HTTP 方法的语义，前端以异步任务调用。
- **RSS 引擎**：独立解析 RSS/Atom、管理订阅与文章，不依赖小说规则引擎。
- **数据与同步层**：SQLite 保存结构化数据，文件系统保存原书及缓存；WebDAV 适配器统一处理目录、读写、重试和备份。

需要明确的核心接口：

| 接口或类型 | 职责 |
|---|---|
| `Book` / `BookAsset` | 分离书架身份与文件位置；换源或移动文件不改变书籍身份 |
| `ReaderLocator` | 保存章节或 EPUB 资源标识、文本偏移及上下文片段，不保存设备页码 |
| `SourceAdapter` | 提供搜索、书籍详情、目录、正文获取及兼容性报告 |
| `FeedService` | 提供订阅导入、刷新、文章列表、已读与收藏操作 |
| `SyncService` / `SyncStatus` | 提供同步、重试、冲突处理，以及前端可订阅的状态事件 |

本地文件用内容哈希识别重复文件；网络书籍使用持久化身份，换源后重新映射章节。无法准确匹配原位置时，返回最接近章节并提示用户。

书源导入支持文件、链接和粘贴 JSON，保留原始配置。兼容范围包括常用选择器、XPath、JSONPath、正则、变量、分页、纯 JS 及有限网络/缓存方法；高级 Java 类调用、Android 专属桥和复杂 WebView 登录不列入首版保证。界面区分“已导入”“未验证”“验证通过”“存在不支持能力”。兼容基准采用[阅读 MD3 官方项目](https://github.com/HapeLee/legado-with-MD3)。

脚本运行环境不拥有界面 IPC 或任意文件访问能力，并设置执行时间、内存和网络超时。EPUB、RSS 正文经过清理后展示。

## 5. 实施顺序与验收

1. **基础验证**：建立三端工程，验证文件导入、SQLite、正文定位、仿真翻页及脚本同步宿主桥。rquickjs 的 Android 集成需实际验证，不能仅凭底层引擎支持作保证。[rquickjs 平台说明](https://github.com/DelSkayn/rquickjs#supported-platforms)
2. **本地阅读闭环**：完成视觉主题、书架、TXT/EPUB 阅读、目录、书签、分页和设置。
3. **网络内容闭环**：完成常用书源导入、搜索、追更、换源，以及独立 RSS 阅读器。
4. **跨端闭环**：完成 WebDAV 云端书库、同步、冲突处理、备份恢复和三端安装包。

重点验收场景：

- 无 WebDAV、无网络时，本地书架和已缓存内容可正常阅读。
- 百万字 TXT、带图片 EPUB 不整本加载到 DOM；跨章节翻页没有漏字、重字，改变排版后保持正文位置。
- 手机读书后在桌面继续，定位到同一段；回看、重读、设备时间偏差不会导致错误覆盖。
- 两端离线修改、同步中断重试、书架删除、备份恢复不丢记录、不重复加书。
- 手动上传的书籍能在另一端下载关联；自动同步和备份中没有正文缓存。
- 用固定页面样本验证书源从搜索到正文的完整链路；不支持的规则给出具体原因。
- RSS/Atom、OPML 分组、重复文章、全文提取失败和已读状态同步行为一致。
- 在 Android、Windows、macOS 验证真实触摸与键盘操作、单双页、字体变化和仿真翻页性能。

首版默认中文界面、单用户个人书库、无自建服务端。以完成上述三端阅读闭环作为发布标准。

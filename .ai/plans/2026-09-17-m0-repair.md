# M0 integration repair

Status: in-progress

## Outcome

Preserve the current visual layout while connecting local import and reading to real services. Complete the original [M0 acceptance](2026-09-17-m0-logic.md), including measured pagination and macOS embedded WebDriver evidence.

## Scope

Repair Rust storage, typed IPC, reading controller, page integration, Tailwind 3.4 components, and verification. Existing uncommitted page work is part of the integration baseline. Deferred discovery, RSS, WebDAV, EPUB, bookmarks, grouping, and cache-management actions remain explicitly unavailable. Android and Windows native acceptance are deferred.

## Interfaces

Rust owns request/response DTOs, library summaries, and preferences. Frontend services separate library jobs, reader content, and settings. Bidirectional windows retain LF-normalized UTF-16 positions. The [recovery decision](../notes/proposed/2026-09-17-import-recovery.md) governs the additive database migration, import journal, and content index. Controller, storage, and presentation implementations have separate ownership and integrate through generated types and service contracts.

## Acceptance criteria

- Native file selection imports actual TXT content; failures never create synthetic books or success notifications.
- Interrupted imports recover consistent database/file state; content changes and missing files surface explicit errors.
- Measured pages are contiguous through Unicode windows, reflow, restart, and backward navigation.
- Reading positions and supported preferences persist independently of animation; stale requests cannot replace current state.
- Current page layouts work at phone and desktop widths, offline, by keyboard and with reduced motion.

## Verification

On 2026-09-18, the local checks passed: `pnpm check`, `pnpm test:native` on macOS, `cargo test --manifest-path src-tauri/Cargo.toml --all-features` (17 tests), `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets --all-features -- -D warnings`, generated-binding freshness, documentation and boundary checks, the frontend test suite (40 tests), `pnpm build`, and an ordinary debug Tauri build. The embedded suite passed core (4), failure/recovery (5), restart (1), and interaction (4) cases in an isolated data directory; it also passed a separate animated WebKit run after the PageFlip initialization fix.

The embedded suite uses direct production IPC for fixture imports because WebDriver cannot control the macOS system file picker. Picker cancellation and picker-driven selection therefore remain manual acceptance evidence. A startup log line is not acceptance evidence.

The suite does not yet automate a native process abort immediately after the managed-file rename. Rust recovery tests cover the journal and rename boundaries; a native crash-and-restart phase remains additional evidence before M0 can close.

## Handoff

Rust storage and IPC now perform staged normalized imports, durable journal recovery, managed-file verification, bounded UTF-16 windows, locator persistence, and settings persistence without holding the shared storage mutex during heavy file work. The reader controller and presentation adapters have measured reflow, bidirectional recovery, serialized navigation, save retry, and PageFlip initialization handling. M0 remains in progress until manual picker evidence and the native crash-recovery evidence are recorded; the owning subsystem specifications remain planned for their wider scope.

# Library

Status: planned

## Scope

Manage book identity, imported assets, shelf membership, groups, reading status, and device availability. File transfer and replication belong to [Sync](sync.md); the shelf presentation belongs to [interaction design](../design/interaction.md). The next planned import and reader slice is tracked in the [active plan](../plans/2026-09-23-import-reader-experience.md).

## Interfaces

`Book` is the persistent identity used for shelf state and reading records. `BookAsset` identifies a local file, cloud file reference, or source-backed content resource. Separate device-local paths and availability from portable identity and metadata.

Use content hashes to detect repeated local assets and a content version to distinguish changed text. Associating or downloading a file updates asset availability without creating a second shelf entry for the same known book. A persistent book ID alone does not establish chapter equivalence between sources; [Sources](sources.md) owns that mapping.

## Behavior

Import TXT and DRM-free reflowable EPUB (title, author, introduction, and cover from the book) through platform file access, single files or folders; desktop also accepts dropped files. A normal TXT import requires only a file choice and runs in the background without opening a progress, metadata, encoding, or confirmation dialog. Picker cancellation is silent. After committed success, refresh the shelf without automatically opening the book. Show dismissible success notices for 3 seconds and failure notices for 8 seconds; pointer or keyboard focus pauses their dismissal. Dismissing a notice never cancels its job or erases its terminal result. After a failure notice expires, keep the latest failure details and retry action available from the import entry. Do not expose incomplete assets as readable books.

The title and author come from the file name with Legado's patterns, widened so 作者 may be followed by any common separator and bracketed edition notes such as （校对版全本） are dropped (for example 《书名》（校对版全本） 作者_某某). The book introduction is the text before the first chapter without a leading 简介 label; title, author, and introduction can be edited later. Use automatic encoding detection for ordinary imports. Legacy-encoding detection samples the first 512 KiB; decoding still covers the whole file, and replacement characters anywhere still reject the automatic guess. Offer an explicit encoding retry at import time only when automatic decoding fails, so successful imports need no encoding step. Keep the reader's encoding action available for later correction of a readable file.

Manage shelf groups and reading states: unread, reading, and finished. A book counts as finished at the end of its last chapter: a local book 98% through (or within its last page), an online book 90% through its last kept chapter; an online book whose contents grew within the 连载判定 range (30 days by default, in 设置 › 书架; 关闭 turns it off) stays in 在读. Introductions keep the first line's indentation. Expose recent reading, chapter updates, progress, and local availability. Read local metadata before performing network work.

Removing a shelf entry removes its shelf membership and replicates that removal when sync is enabled; it does not delete the remote original book. Clearing cached chapters affects only this device. Permanent asset deletion, if later added, must be a distinct operation with its own scope.

A local-book record with no file offers cloud download when an asset is available remotely, or local-file association. A source-backed book without cached chapters offers chapter retrieval through its source. Do not show a downloaded state until content is actually available.

Imported originals, chapter caches, and derived indexes have separate ownership so cache cleanup cannot remove original books or structured reading records. Failed imports do not leave apparently readable shelf entries pointing to incomplete assets.

## M0 implementation contract

Native file selection accepts one or more TXT files. On Android the picker returns a document URI; the command layer stages a copy named after the document display name and removes it when the operation ends, as recorded in the [Android document import decision](../notes/implemented/2026-10-10-android-document-import.md). The encoding behavior is owned by [the TXT decoding decision](../notes/implemented/2026-09-18-txt-m1.md). Cancelling the picker creates no task. Application-owned tasks continue after the import panel closes; polling and events converge on one terminal state. A completed import includes its committed result. Shelf snapshots, including an empty snapshot, are authoritative. Unknown metadata uses explicit defaults.

Imports prepare the representation used by decoding, content versions, positions, search, and recovery outside the database mutex. Required conversion detects the encoding, removes its BOM, and normalizes CRLF/CR to LF; it does not rewrite prose or remove paragraphs. Measure file reading, decoding/conversion, hashing and indexing, staging writes/synchronization, commit, shelf refresh, and time to first readable page separately before optimizing repeated work. The name of a progress phase is not evidence that its named step is the bottleneck. A durable import journal records ownership before file publication; startup obtains exclusive access and reconciles journal entries and committed assets. Recovery removes incomplete products and retains committed identities and valid positions. Reconstructible sparse UTF-16/byte indexes accelerate bounded reads. Managed-file identity and metadata invalidate the verified content cache; changed content produces an explicit version error.

## Local group implementation

The shelf shows 全部 and the reading states 在读, 未读, and 读完, then user groups. A book appears in one group besides 全部: its user group, a reading state the reader moved it to, or the state derived from its progress, as recorded in the [reading-state shelf groups decision](../notes/implemented/2026-10-10-reading-state-shelf-groups.md). Moves happen on the book detail page and hold until the next move; deleting a user group returns its books to automatic grouping and preserves books, assets, and reader locators. The generated Rust contracts own validation and IPC shapes.

The application shelf store serializes group reads and mutations, and reloads the books after a move. Chapter metadata loads independently with a book-snapshot revision, retains verified same-version entries on failure, and exposes per-book errors for retry; the automatic states derive from the same listing. Views consume the authoritative group snapshot, use generated covers unless the reader chose an image, and never match a filename to sample catalog data.

## Book detail and records

Long-pressing a book opens its detail page after Legado's book information: cover, title, author, file size, encoding, chapter count, current and latest chapter, progress, reading time, a wrapping introduction, the group, and the actions continue reading, contents, edit (title, author, introduction, cover), and remove from shelf. A cleared introduction stays empty instead of being refilled by chapter detection. Covers are PNG, JPEG, WebP, or GIF files up to 20 MB copied into managed assets; replacing or clearing a cover deletes the previous file.

The reader adds reading time per local day while the page is visible and the reader touched the screen, pressed a key, or turned a page within five minutes, or while automatic turning runs. The 阅读记录 page shows today's and total time, an activity matrix that opens at today with a fixed weekday column, and time per book by the last reading, newest first; a long press deletes a book's record after a confirmation. Several files can be chosen at once, and 导入文件夹 imports every TXT in a folder and three levels of subfolders, one after another, with one summary notice.

## Online books

Online books are `books` rows with an `online_books` record (the source's details and switches) and an `online_chapters` table; they have no asset. Chapter texts are kept under the app's `online/<book id>/` folder as the source returned them, named by position and a hash of the title, and are fetched on first read, ahead in the background (the next chapter first, then the 预下载章节数 setting, ten by default and up to 50, and three behind; a chapter failing three times is skipped), or by 下载管理. Its app-wide queue keeps downloading after the page that added a job closes: books download a few at a time with several chapters in flight each (网络设置's limits), a failed chapter is asked for three times, and the queue is kept in `downloads.json` so unfinished jobs return paused after a restart. On Android a foreground service shows the progress in a notification whose 停止 pauses every job. 下载管理 in the shelf menu lists jobs with progress, 暂停, 继续, 取消, and 清除已完成, and adds chosen shelf books; 缓存 on the detail page and in the reader's top bar takes 后面 50 章, 后面全部, 全部, or a chapter range by number. 设置 › 数据管理 (in the 更多 group) shows the total of the clearable caches over the data folder's stacked bar by part, with 清理所选: books read off the shelf, the shelf's chapter caches, covers, the sources' details and contents cache, and logs can be cleared, all chosen by default except the shelf's chapters, which only go when chosen; local books, assets, recovery points, and the database are shown only. It lists each shelf online book with its cached and total chapters and a 清除, and 退出时清理缓存 (off by default) clears the default parts when the app next starts. When every chapter is cached, the detail page's 缓存 menu offers 转为本地书籍: the chapters with their title lines become one UTF-8 TXT imported as usual, the position and bookmarks move to the same places, the reading time, group, state, cover, author, and introduction move to it, and the online book is deleted. 更新目录 (shelf menu, pulling the shelf down, book detail page, or reader menu) fetches the details and contents again for books that allow updates, a few at a time, and 自动更新 (设置 › 书架, on by default) runs it on entering the shelf at most every ten minutes, speaking up only about new chapters or failures; every shelf cover shows the chapters left after the one being read (all of them when unread), red when the book gained chapters since it was last read and grey otherwise, the latest-chapter line marks chapters the last update added until the book is opened, and 更新失败 shows when the last update failed. The shelf matches an online book by name and author as Legado does. 移出书架 and 删除 delete an online book with its cache instead of moving it to the 回收站. The detail page shows the source, chapter and cached counts (with the kept text's 总字数; local books show the whole text's),  the chapter read and the latest one, and offers 更新目录, 缓存, 允许更新, and 删除. Online books are not uploaded to the cloud bookshelf, and progress sync and backups for them come with source switching.

Deleting a book keeps its reading time, title, and author in `retired_books` under the original file's hash (an online book under its name key), so 阅读记录 still lists it; re-importing the same file returns the time to the book. 书源管理's 智能排序 lists enabled sources without a failed check first, then by response time, weight, and manual order.

## Acceptance

- Reimport identical content without duplicating its asset; preserve book identity when its local path changes.
- Complete normal import with only a file choice; success and failure notices expire or dismiss without changing job outcomes, and picker cancellation remains silent.
- Offer explicit import-time encoding retry only after automatic decoding failure; interrupted or failed imports leave no apparently readable partial asset.
- Compare import, commit, shelf refresh, and first-readable-page timings independently on representative TXT sizes before attributing slowness to representation conversion.
- Manage groups, reading state, recent books, and local availability across restarts.
- Distinguish shelf removal, cache cleanup, and cloud-file operations: 移到回收站 keeps everything and can be undone; 删除 removes the book and the app's own copies of its text, original file, and cover, keeping the cloud file, while its progress, bookmarks, and reading time are kept by the original file's hash (reading time stays in the totals) and return when the same book is imported or downloaded again; 本地与云端一起删除 also deletes the cloud file. The reader's original TXT outside the app is never touched. Reading records list books in the 回收站 as such and open their detail page, not the reader.
- Associate or download a missing local-book asset and retrieve uncached source chapters through the appropriate path.
- Interrupt an import and verify incomplete content is not reported as ready.

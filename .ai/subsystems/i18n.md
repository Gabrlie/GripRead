# Interface languages

Status: planned

## Scope

The interface is shown in 简体中文 (the default) or English, chosen on the device. Book content, source rules, and log lines are not interface text and stay as they are.

## Interfaces

`src/i18n/` owns the dictionaries:
- `zh-CN` defines the keys;
- other languages are typed against those keys, so a missing string fails the typecheck.

Pages read text through `t(key, params)` and format dates through the locale helpers there. Errors from the core carry an optional message key with parameters next to their Chinese message; the interface translates the key and falls back to the message.

## Behavior

**Choosing the language:**
- 界面语言 offers 跟随系统, 简体中文, and English.
- The choice is device-local: kept in browser storage for the first render and mirrored to the core for its messages. It is never synced or backed up.
- The web version follows the browser unless chosen there.
- The page's `lang` attribute follows the choice.
- Dates and times use the chosen locale. Title sorting keeps Chinese collation.

## Acceptance

- Switching language changes open screens at once and survives a restart.
- Every key exists in every language (typecheck).
- An error with a key shows in the chosen language; one without shows its message.
